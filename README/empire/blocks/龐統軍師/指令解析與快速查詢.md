# 指令解析與快速查詢

## 指令流程

```text
使用者輸入自然語句
    ↓
advisorAICommand()：V1 本地規則
    ├─ 命中 → 直接執行或顯示確認
    └─ unknown → advisorAIDeepSeekCommand()
                    ↓
              advisorAiParse
                    ↓
              正規化 intent
                    ↓
              執行查詢／導頁／待確認寫入
```

V2 後端只應回傳 JSON object，不回傳 Markdown。解析結果會再經過 `advisorAINormalizeDeepSeekCommand()`，不符合安全欄位或 intent 白名單時應視為未知。

## 支援的 intent

前端目前允許的 AI intent：

`transfer`、`dividend`、`advisorDividendMemo`、`stockSell`、`open`、`maintenance`、`copyCarrier`、`showCarrier`、`member`、`unknown`。

目前前端不再接受 `expense` 作為 AI 口令 intent；支出改由龐統上方的快速支出表單直接送出 `expense` API。Apps Script 仍保留 `expense` action，供快速表單與內政快速記帳使用；後端 AI prompt 的歷史 `expense` 定義仍需另行清理，不能把它誤寫成前端可用口令。

前端另有本地處理的查詢／流程，例如：

- `schedule`：今日行程與待辦。
- `monthlyAssetBrief`：本月資產摘要。
- `accountLookup`：帳戶餘額。
- `stockBuy`：股票買入確認。
- 退稅查詢、載具、會員卡與配息入帳快捷流程。

## 常用口令範例

| 類型 | 範例 | 注意 |
| --- | --- | --- |
| 轉帳 | `國泰s 轉 現金 1000` | 需確認來源、目的與金額 |
| 配息入帳 | `AIPI 3249` | 這是已入帳金額，和配息備忘不同 |
| 股票賣出 | `賣出 100股 IAU 156000` | 會先顯示交易確認 |
| 股票買入 | `買入 12.02股 施羅德 54000` | 會先顯示交易確認 |
| 導頁 | `打開財政` 等 | 只允許後端提示詞列出的面板鍵 |

## 快速查詢

軍師快速選單目前包含：`快速轉帳`、`配息記錄`、`顯示載具`、`超商會員`、`退稅查詢`與`複製載具`。

### 快速支出

快速支出不是口令解析功能。龐統主面板直接使用內政設定中的消費項目與支出帳戶下拉選單，輸入金額後按 `📝`，呼叫 `expense` 寫入；因此不會與配息入帳口令互相誤判。

### 配息記錄

從常用查詢開啟「配息記錄」後，選擇持股標的並輸入每股配息比例，前端依持股數、台美股規則、匯率與稅率計算預估台幣金額，再由 `advisorDividendMemo` 寫入待入帳配息。美股標的包含 `QQQI`、`AIPI`、`MLPI`、`PLTY`、`CHPY`、`GDXW`、`GLDW`；美股一般套用匯率與 0.7 稅後係數，施羅德收益成長 A2 為美股但免先扣 30%。每次成功寫入後會重新載入配息中心，才能連續切換其他標的試算。

常用查詢 API 包含：`accounts`、`foodhouseDashboard`、`dividendCenter`、`marketDashboard`、`todayCalendar`、`todayTasks`、`monthly`、`holdingsOverview`。

## 維修注意

- 修改解析規則時，同步檢查本地 V1、Apps Script DeepSeek 系統提示詞與 `advisorAINormalizeDeepSeekCommand()`；若是支出功能，優先檢查快速表單而不是新增口令規則。
- 代稱要維持正規化規則，例如帳戶與投資標的不能只靠顯示名稱硬比對。
- 不要讓 AI 自由產生 Apps Script action；action、欄位與導頁面板都應維持白名單。
